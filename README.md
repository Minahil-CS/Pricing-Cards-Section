### 💎 Modern Responsive Pricing Cards Section

A sleek, ultra-modern, and fully responsive Pricing Cards Section component built with pure HTML5, CSS3, and JavaScript. Features smooth price-toggling animations, ambient glassmorphism design, custom toast notifications, and full mobile-to-desktop responsiveness.

## ✨ Features

📱 Fully Responsive Layout: Automatically adapts seamlessly across Mobile, Tablet, and Desktop screens.

⚡ Interactive Pricing Toggle: Switch between Monthly and Annual billing cycles with dynamic number transitions (Save 20% discount integration).

🎨 Modern Glassmorphism UI: Built with dark theme aesthetics, subtle gradient borders, backdrop blurs, and hover micro-interactions.

🔔 Toast Notifications: Interactive user feedback when selecting pricing tiers without disruptive popup alerts.

🚀 Zero Dependencies: Built using lightweight vanilla Web technology (HTML, CSS, JS) with FontAwesome icons.

## 🛠️ Built With

HTML5: Semantic structural markup.

CSS3: Custom properties (CSS variables), Flexbox, CSS Grid, animations, and media queries.

JavaScript (ES6+): Dynamic DOM updates, price switching logic, and event handling.

FontAwesome: Scalable iconography.
